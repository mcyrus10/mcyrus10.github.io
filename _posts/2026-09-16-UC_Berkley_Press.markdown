This is a project I contributed to with tomographic reconstructions of a replica scroll. A program that I wrote for unwrapping battery tomograms was repurposed for the scroll which exhibits an irregular spiral. Using the normals to a spline that traced the layers we were able to digitally unwrap the scroll and read the text written with lead-based ink.
